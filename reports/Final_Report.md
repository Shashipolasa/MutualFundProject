# Mutual Fund Analytics Project

## 1. Project Overview
This project analyzes mutual fund performance using historical NAV data and investor transaction data.

## 2. Objectives
- Analyze fund performance
- Calculate CAGR
- Calculate Sharpe Ratio
- Measure Risk using VaR
- Recommend top-performing funds

## 3. Data Sources
- NAV History
- Scheme Performance
- Investor Transactions

## 4. ETL Process
- Data ingestion
- Data cleaning
- Missing value handling
- SQLite loading

## 5. Exploratory Data Analysis
- NAV Trends
- AUM Growth
- Investor Distribution

## 6. Performance Analytics
### CAGR
Annualized return of a fund.

### Sharpe Ratio
Risk-adjusted return metric.

### Volatility
Standard deviation of returns.
