# Mutual Fund Analytics Capstone Project

## 1. Executive Summary

This project analyses mutual fund performance using NAV history,
scheme performance and investor transaction data.

Key metrics calculated:
- Annual Return
- CAGR
- Annual Volatility
- Sharpe Ratio
- Value at Risk (VaR)

A recommendation engine was built to identify high-performing funds.

---

## 2. Data Sources

- NAV History
- Scheme Performance
- Investor Transactions

Total Funds Analysed: 40
